# AGENTS.md

## Repository description
This repository contains the presentation slides and abstracts for the PhD of Mika Mäki
on Searching stochastic backgrounds in LISA data for signals from a phase transition in the early universe.

## Code structure
- Each presentation is in its own directory with the naming convention `./YEAR_CONFERENCE`
- The presentations are made with reveal.js, and the abstracts are in Markdown.
- `index.html` contains links to the conference websites.

## Relevant sources
- PTtools may be available at `../pttools`
- PTPlot may be available at `../PTPlot`
- Mika's MSc thesis
  "The effect of sound speed on the gravitational wave spectrum of first order phase transitions in the early universe"
  is on arXiv as [arXiv:2511.20436](https://arxiv.org/abs/2511.20436).
  Its LaTeX source code and Python scripts may be available at `../msc-thesis2`.
- The physics is based on the Sound Shell Model by Mark Hindmarsh, which was published in
  [arXiv:1909.10040](https://arxiv.org/abs/1909.10040).
- A review of phase transitions in the early universe is provided by
  [arXiv:2008.09136](https://arxiv.org/abs/2008.09136).
